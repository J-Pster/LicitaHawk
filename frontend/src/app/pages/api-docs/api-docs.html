Início rápido

  1. Crie uma chave na tela API keys.
  2. Envie-a em toda chamada no header Authorization: Bearer <chave> (ou X-Api-Key: <chave>).
  3. Faça sua primeira chamada:

Toda resposta de sucesso devolve os dados no campo data; buscas paginadas também trazem next_cursor quando há mais páginas.

Toda resposta de erro segue o mesmo formato, com um code estável para tratar por máquina (ex.: VALIDATION_ERROR, NOT_FOUND, UNAUTHORIZED, RATE_LIMITED, PLAN_LIMIT_EXCEEDED) em vez de depender do texto de message, que é em português e pode mudar.

Limites

Dois limites distintos, aplicados juntos em toda chamada autenticada, e que não se confundem:

Plano Limite mensal Limite por minuto
Free 100 requisições/mês 30 requisições/min
Starter 5.000 requisições/mês 180 requisições/min
Pro 50.000 requisições/mês 600 requisições/min

Estourar qualquer um dos dois responde 429: o mensal vem com code: PLAN_LIMIT_EXCEEDED, o por minuto vem com code: RATE_LIMITED e o header Retry-After. Os headers X-RateLimit-Limit e X-RateLimit-Remaining aparecem em toda resposta autenticada e refletem sempre o limite por minuto. Acompanhe seu consumo em Uso.
